Connect Google Drive

A one-time, ~10 minute setup so Google lets Folio open your Docs and Slides. You only ever do this once.
  1. Create a free Google Cloud project. Open Google Cloud →
    Name it “Folio” and click Create. No credit card needed.
  2. Turn on three APIs (click Enable on each): Drive · Docs · Slides
  3. Set up the sign-in screen. Open Google Auth Platform →
    Click Get started, app name “Folio”, your email, audience External. Then under Audience → Test users, add your own Gmail address (and your school email, if you'll sign in with that).
  4. Create the app key. Open Clients →
    Create client → type Desktop app → Create → Download JSON.
  5. Load that file into Folio and you're done.
School accounts often can't open Google Cloud — make the project with a personal Gmail instead.

Google Drive, no sign-in

For school accounts that block outside apps. Folio makes the files on this PC, then opens Google Drive and the project folder side by side.
  1. Make your project with Save to set to Google Drive.
  2. On the result screen, click Add to Google Drive.
  3. Drag the .pptx / .docx from the folder into Drive.
  4. Right-click the file in Drive → Open with → Google Slides (or Docs) → File → Save as Google Slides. To add to a deck you already have, open it and use File → Import slides.

Classroom

See what's due, then fill in the file already attached to the assignment. Folio drafts the work and writes it into your existing Google Doc or Slides — it never makes a new file and never turns anything in.
How it works
  1. Click Open Classroom window. Sign in with your school account there (only the first time; Folio never sees your password).
  2. Click Load my assignments. Folio reads your To-do list.
  3. Click Start project on an assignment. Folio reads its instructions, rubric and your teacher's comments and drafts the work — then, on the next screen, writes it into the file already attached to that assignment (your Google Doc or Slides). You check it and turn it in yourself.
